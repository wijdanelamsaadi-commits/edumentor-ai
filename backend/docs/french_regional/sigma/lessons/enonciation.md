Définition:
La situation d’énonciation:
Un énoncé est un message écrit ou oral produit par un émetteur (locuteur) s’adressant
à un destinataire. L’analyse d’un énoncé doit prendre en considération la situation de
l’énonciation.
C’est la situation dans laquelle un message a été produit: qui parle? A qui? Quand? Où?
Il y a deux systèmes d’énonciation: le discours et le récit.
Les deux systèmes d’énonciation:
Discours:
C’est un énoncé ancré dans la situation d’énonciation et dans lequel celui qui parle
s’implique.
Les caractéristiques du discours:
Les pronoms personnels:
- Emetteur:
je, me, moi, nous.
- Récepteur:
tu, te, toi, vous.
Les adjectifs possessifs:
- Emetteur:
Mon, ma, mes, notre, nos.
- Récepteur:
ton, ta, tes, votre, vos.
Les pronoms possessifs:
- Emetteur:
le mien, la mienne, les miens, les miennes.
- Récepteur:
le tien, la tienne, les tiens, les tiennes.
Les temps dominants:
Présent de l’énonciation, passé composé, futur... (Tous les temps
peuvent être utilisés sauf le passé simple et le passé antérieur)
Les indications temporelles:
Aujourd’hui, à ce moment, maintenant, hier, avant-hier,
demain, après demain, la semaine prochaine, la semaine précédente, dans un an, etc.
Les indications spatiales:
Ici, là, là-bas, près, loin, en-haut, en bas, au-delà, à gauche, à
droite, etc.
Formes privilégiées:
Les conversations, le dialogue dans un récit, le théâtre, les émissions
télévisées, les lettres, messages publicitaire, discours politiques, les journaux intimes, les
interventions directes du narrateur pour ses lecteurs...

## Page 10 — L'énonciation : discours et récit

Récit:
C’est un énoncé coupé de la situation de communication et qui établit une distance entre
ce qui est raconté et le présent de celui qui raconte.
Les caractéristiques du récit:
Les pronoms personnels:
-
Emetteur:
Ils(s), elle(s), le, la, les, lui, leur, les noms des personnages de l’histoire.
- Récepteur:
Pas d’indice pour le récepteur.
Les adjectifs possessifs:
- Emetteur:
Son, sa, ses, leur, leurs
- Récepteur:
Pas d’indice pour le récepteur.
Les pronoms possessifs:
- Emetteur:
Le sien, la sienne, le/la leur, les leurs
- Récepteur:
Pas d’indice pour le récepteur.
Les temps dominants:
Passé simple, imparfait, plus-que-parfait, conditionnel, présent de la
narration.
Les indications temporelles:
La veille, l’année précédente, un jour, le lendemain, deux mois
plus tard, etc.
Les indications spatiales:
A Fès, au premier étage...
Formes privilégiées:
Romans, nouvelles, contes, fables, ouvrages historiques...
