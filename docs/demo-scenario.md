# Scénario de démonstration

1. Créer un compte ou se connecter avec Google.
2. Passer le test diagnostique et observer le niveau obtenu.
3. Consulter le Dashboard : niveau, progression, recommandations.
4. Ouvrir `Mes cours`, choisir un support IA.
5. Dans le détail du cours, parcourir les chapitres et utiliser `Chapitre suivant`.
6. Lancer le quiz du cours, consulter le score, la correction et la recommandation.
7. Ouvrir le Chatbot IA :
   - `C'est quoi le RAG ?` montre une réponse basée sur les supports avec sources.
   - `What is overfitting?` utilise la réponse générale Groq.
   - `météo` déclenche la réponse hors sujet.
8. Ouvrir `Ressources`, télécharger un PDF et vérifier la notification.
9. Ouvrir `Profil & Progression`, vérifier les badges, historique et certificat.
10. Avec un admin, ouvrir `/admin` et vérifier utilisateurs, cours, statistiques, RAG et audit.
